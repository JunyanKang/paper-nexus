# 安装与更新

[返回首页](../README.md) · [开始使用](GUIDE.md) · [常见问题](FAQ.md)

当前版本 **0.4.10**。请从 [发布页](https://github.com/JunyanKang/paper-nexus/releases/tag/v0.4.10) 下载完整 XPI；已有用户也可通过自动更新或插件内“检查更新”升级。

## 安装 Paper Nexus

1. 确认 Zotero 版本为 **10.0.5–10.0.x**。
2. 获取 **paper-nexus-版本号.xpi** 完整包；公开版本可从 [发布页](https://github.com/JunyanKang/paper-nexus/releases/latest) 的 Assets 下载。
3. 在 Zotero 中依次打开 **工具 → 插件 → 齿轮 → 从文件安装插件**。
4. 选择下载的 XPI，按 Zotero 提示完成安装。
5. 打开 PDF，在工具栏找到 Paper Nexus 纸张放大镜图标。

下载后不需要解压 XPI，也不需要安装 Python、Node.js 或注册额外账户。浏览器若把 XPI 保存成 ZIP，请恢复 `.xpi` 扩展名后再安装。

## 模型已经在安装包里

通用 XPI 约 **22.5 MB**，已包含量化 **all-MiniLM-L6-v2** 语义模型、分词器与本地运行组件。其他用户只需安装这个 XPI，不需要再下载模型、安装训练环境或填写 API Key。

| 安装包 | 包含内容 | 适用方式 |
|---|---|---|
| 通用版 `paper-nexus-版本号.xpi` | 基座模型与运行组件 | 日常安装，直接分析自己的文献库 |
| 个人适配版 `paper-nexus-版本号-personal.xpi` | 通用版全部内容，另加为特定文献库生成的适配参数 | 单独提供给相应用户，不是通用版的前置依赖 |

个人适配参数不会替代基座模型，也不携带训练书目。普通用户无需个人适配版；两种包沿用同一插件身份，选择其中一个安装即可。

## 第一次打开文献网络

选择自己的文献库或文献夹后，插件读取题名、已有摘要和作者信息，在本机生成网络：

- **主题**：本地模型计算研究内容的相似关系，按主题组织论文；只有题名也可参与。
- **作者**：按完整署名汇总论文，用共同发表的论文连接作者。
- **后续变化**：新文献、修改和删除在后台更新，已完成的计算尽量复用。

首次建立索引会显示处理进度。这个过程是使用已训练好的模型分析文献，不会重新训练模型；每位用户的网络由自己的文献库生成。

本地主题分析无需联网。PubMed／PMC 摘要查询、在线翻译，以及用户启用的大模型主题命名需要联网；大模型服务按所选厂商要求配置密钥。

## 第一次阅读

悬停正文中的引用标记，查看对应文献卡片。悬停卡片题名打开摘要；点击书签稍后阅读，或点击保存将文献放入 Zotero 文献夹。

![正文引文卡片](images/hover.png)

点击工具栏图标打开本篇参考文献列表，再点一次收起。点击主面板的网络图标，可浏览本地作者与主题网络。

## 更新

在 Paper Nexus 中打开 **齿轮 → 常规**，在页面底部点击 **检查更新**。发现新版本后，点击安装按钮。

<img src="images/settings-general.png" width="324" alt="常规页的更新入口" />

开启“自动更新”后，Zotero 会按自身更新机制检查新版本。若 Zotero 的全局插件更新已关闭，可继续使用手动检查；也可以重新下载最新 XPI，在同一个插件管理页面安装。

早期 **CiteLens 0.3.3** 用户请手动安装一次新版 XPI。升级沿用原插件身份，原有设置和稍后阅读清单继续保留。
