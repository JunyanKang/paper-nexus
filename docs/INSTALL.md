# 安装与更新

[返回首页](../README.md) · [开始使用](GUIDE.md) · [常见问题](FAQ.md)

当前版本 **1.0.0**。macOS 和 Windows 使用同一份 XPI 和模型包。

## 首次安装

1. 确认 Zotero 版本为 **10.0.5–10.0.x**。
2. 在 [发布页](https://github.com/JunyanKang/paper-nexus/releases/latest) 下载 **paper-nexus-1.0.0-mac-windows.zip**，解压到任意文件夹。
3. Zotero → **工具 → 插件 → 齿轮 → 从文件安装插件**，选择其中的 `.xpi`。
4. 打开 PDF，点击 Paper Nexus 图标，再打开 **设置 → 常规 → 本地模型**。
5. 点击导入图标，选择完整包内的 `.pnmodel`。完成后即可打开本地文献网络。

无需安装 Python、Node.js 或后台服务。XPI 文件本身无需解压；浏览器若改成 `.zip` 后缀，请恢复 `.xpi`。

也可以只下载 XPI，再在“本地模型”一行点击安装，直接下载模型。离线或网络较慢时，优先使用完整包导入。

## 模型只安装一次

插件、模型和个人文献索引分别保存。日后升级 XPI 不会重复下载模型，也不会删除已有索引。

| 下载项 | 用途 |
|---|---|
| `paper-nexus-1.0.0.xpi` | 插件安装与日常更新，约 2.3 MB |
| `paper-nexus-1.0.0-mac-windows.zip` | 首次安装完整包：插件、轻量模型和安装说明 |
| `paper-nexus-minilm-1.0.0.pnmodel` | 默认轻量通用模型，约 20.1 MB |
| `paper-nexus-medembed-1.0.0.pnmodel` | 可选生命医学模型，约 29.0 MB |

轻量模型适合日常使用。生命医学模型面向英文生物医学内容，首次处理较慢；可以在同一设置行切换。两者的索引分别保存，切回原模型可复用先前计算。

模型行的检查图标用于检查**模型更新**；页面底部“检查更新”用于更新**插件**。导入或下载失败可重试，已安装的可用模型会保留。

从 0.4.x 升级到 1.0 时，需要首次安装独立模型包；旧版兼容的轻量模型向量缓存会自动导入。引文阅读、作者网络不需要语义模型。

## 第一次打开文献网络

选择自己的文献库或文献夹后，插件读取题名、已有摘要和作者信息，在本机生成网络：

- **主题**：本地模型计算研究内容的相似关系，按主题组织论文；只有题名也可参与。
- **作者**：按完整署名汇总论文，用共同发表的论文连接作者。
- **后续变化**：新文献、修改和删除在后台更新，已完成的计算尽量复用。

首次建立索引会显示处理进度。这个过程是使用已训练好的模型分析文献，不会重新训练模型；每位用户的网络由自己的文献库生成。

本地主题分析无需联网。PubMed／PMC 摘要查询、在线翻译，以及用户启用的大模型主题命名需要联网；大模型服务按所选厂商要求配置密钥。

## 第一次阅读

悬停正文中的引用标记，查看对应文献卡片。悬停卡片题名打开摘要；点击书签稍后阅读，或点击保存将文献放入 Zotero 文献夹。

![正文引文卡片](images/hover.png)

点击工具栏图标打开本篇参考文献列表，再点一次收起。点击主面板的网络图标，可浏览本地作者与主题网络。

## 更新

在 Paper Nexus 中打开 **齿轮 → 常规**，在页面底部点击 **检查更新**。发现新版本后，点击安装按钮。

<img src="images/settings-general.png" width="324" alt="常规页的更新入口" />

开启“自动更新”后，Zotero 会按自身更新机制检查新版本。若 Zotero 的全局插件更新已关闭，可继续使用手动检查；也可以重新下载最新 XPI，在同一个插件管理页面安装。

早期 **CiteLens 0.3.3** 用户请手动安装一次新版 XPI。升级沿用原插件身份，原有设置和稍后阅读清单继续保留。
