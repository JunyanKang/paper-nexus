# 安装与更新

[返回首页](../README.md) · [开始使用](GUIDE.md) · [常见问题](FAQ.md)

## 安装 Paper Nexus

1. 确认 Zotero 版本为 **10.0.5–10.0.x**。
2. 打开 [最新发布页](https://github.com/JunyanKang/paper-nexus/releases/latest)，在 Assets 中下载 **paper-nexus-0.4.6.xpi**。
3. 在 Zotero 中依次打开 **工具 → 插件 → 齿轮 → 从文件安装插件**。
4. 选择下载的 XPI，按 Zotero 提示完成安装。
5. 打开 PDF，在工具栏找到 Paper Nexus 纸张放大镜图标。

下载后不需要解压 XPI，也不需要安装 Python、Node.js 或注册额外账户。浏览器若把 XPI 保存成 ZIP，请恢复 `.xpi` 扩展名后再安装。

## 第一次阅读

悬停正文中的引用标记，查看对应文献卡片。悬停卡片题名打开摘要；点击书签稍后阅读，或点击保存将文献放入 Zotero 文献夹。

![正文引文卡片](images/hover.png)

点击工具栏图标打开本篇参考文献列表，再点一次收起。点击主面板的网络图标，可浏览本地作者与主题网络。

## 更新

在 Paper Nexus 中打开 **齿轮 → 常规**，点击 **检查更新**。发现新版本后，点击安装按钮。

<img src="images/settings-general.png" width="324" alt="常规页的更新入口" />

开启“自动更新”后，Zotero 会按自身更新机制检查新版本。若 Zotero 的全局插件更新已关闭，可继续使用手动检查；也可以重新下载最新 XPI，在同一个插件管理页面安装。

早期 **CiteLens 0.3.3** 用户请手动安装一次新版 XPI。升级沿用原插件身份，原有设置和稍后阅读清单继续保留。
