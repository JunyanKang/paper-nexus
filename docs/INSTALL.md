# 安装与更新

[产品首页](../README.md) · [使用指南](GUIDE.md) · [常见问题](FAQ.md)

适用于 **Zotero 10.0.5–10.0.x**。macOS 与 Windows 使用同一个 XPI 文件。

## 安装 Paper Nexus

1. 从[官方发布页](https://github.com/JunyanKang/paper-nexus/releases/latest)下载 **paper-nexus-1.1.0.xpi**，无需解压。
2. 打开 Zotero，进入 **工具 → 插件**。
3. 点击右上角齿轮，选择 **从文件安装插件**，选中刚下载的 XPI。
4. 按 Zotero 提示完成安装；如提示重启，重启后打开一篇 PDF。

文献库工具栏的 Nexus 图标可直接打开朋友圈。打开 PDF 后，阅读器工具栏的同一图标可查看本篇参考文献；悬停正文引文可展开文献卡片。

## 更新已有插件

在 Paper Nexus 的 **设置 → 阅读** 底部点击 **检查更新**，或开启自动更新。也可以按上述步骤安装新版 XPI。设置与稍后读清单会保留。

## 找不到下载的文件

通常位于系统的 **下载** 文件夹。若浏览器把文件保存成 ZIP，请保留或恢复 `.xpi` 扩展名，不要解压后安装。
