# 五轮角色模拟评审 · 0.4.0

这是基于代码、实际 Zotero 截图和交互测试的角色模拟，不是对真实 PI、教授或研究生的访谈，也不代表用户研究数据。每轮均检查必要性、功能、视觉和操作成本，发现问题后修改实现，并在后续截图／测试中复查。所有截图来自隔离 Zotero 的真实界面，不是设计稿。

## 逐轮记录

| 轮次 | PI 视角 | 研究生视角 | 教授视角 | 代码和视觉发现 → 实际修改 |
|---|---|---|---|---|
| 1：科研信息与结构 | 连接的依据比节点数量重要 | 文献列表必须先能读、能打开 | 主窗口不应被大图占满 | 原生引文直接继承链接；网络列表题名高度为零；默认图挤占空间。正文与文末逐项复核；剔除明显冲突候选；改为列表优先、图按需打开；修正题名样式。截图随后仍暴露主文档旧样式未清理，带入下一轮 |
| 2：阅读动线与品牌 | 同名署名不能等同作者身份 | 搜索后不能看到另一篇旧选中项；打开 PDF 后应立即能读 | 同系列 Logo 应有识别度且克制 | 新 Logo 在阅读器中为空；样式更新后文字溢出按钮。接入宿主内容可访问资源、卸载清理主文档样式；保持全库选择和过滤器；清除过期搜索结果；打开条目／附件时关闭遮罩 |
| 3：密度、方向、键盘 | 箭头需要明确引用方向 | 图与列表应能互相定位，回退不能丢过滤条件 | 长作者名单不应撑满头部 | 原生主窗口 CSS 给按钮固定高度，标题重叠。显式取消固定高度；关系边加方向和图例；同一条引用不重复显示泛化“相关条目”；作者前三后三，完整名单按需展开；加入键盘缩放平移及取消拖动处理 |
| 4：异常、窄窗与主题 | 不可读附件与未索引附件需要区分 | 输入变化后旧全文片段不能留着误导 | 深色、高字号、小窗口仍应可用 | 加入无结果／取消／读取错误状态；全库刷新不恢复成单库；查不到附件时禁用打开全文；增加 collection 路径；窄屏堆叠列表与详情。真实 620 px 深色、420 px 明亮和 360 px 高字号设置检查通过 |
| 5：匹配可信度与交付 | 错误 DOI 和作者年份冲突不能自动入库 | 明显错误候选应消失；合理的出版年差异才值得选择 | 原始题名与候选要方便直接对比 | 清理文末条目混入的重复页眉 DOI；修正复姓、连续年份和 et al. 消歧；缓存重新过滤；候选窗口直接显示原题名与年份、六位作者，无候选不弹窗。核对三篇真实 PDF 中的 24 组重点引文，并验证错误原生目标不会改变复核结果。之后执行完整回归和生产包安装／更新验证 |

## 界面、按钮与字段去留

| 界面／元素 | 必要性与保留方式 | 功能检查 |
|---|---|---|
| 阅读器“研联”入口／工具菜单 | 图标与名称统一；无阅读器时仍可进入本地网络 | 内容资源加载；卸载无残留；避免重复入口 |
| 单篇悬浮卡：类型／年、题名、作者、期刊／出版社 | 确定文献身份；作者一行，≤6 全列，>6 前三…后三；题名常见上下标／斜体安全渲染 | 原始书目、书籍、章节、实体符号、长题名 |
| IF／Q／DOI | 期刊行末；IF 一个数字、Q1 简写、DOI 可跳转；JCI 与指标年放提示中 | 窄窗同一行；多学科最佳分区明确提示；书籍不显示期刊指标 |
| 保存／打开、稍后读、… | 右上角；存在库中时显示完整文献夹路径；不占额外底行 | 保存去重；同库关联；重复记录选择；跨库位置 |
| 多篇选择／上一篇／下一篇 | 一次一张卡，选择器显示身份，避免无限长窗口 | 每个正文身份单独对应文末条目；不采用整篇作者集合 |
| …四项 | 仅“更新信息、另存到…、复制引用、设置” | 鼠标／方向键／Esc／弹层边界；后台不自动打开候选 |
| 候选窗口：原始题名、年份、作者、候选与保留按钮 | 只留合理候选；不显示人为准确率；原始全文按需展开 | 标题／作者／作者列表／年份／DOI 冲突过滤；缓存亦重新判断 |
| 保存窗口：库／文献夹、新建、编辑书目、其他位置、保存／取消 | 目标选择优先；高级字段折叠；未核实书目需明确确认才能写入 | 新建子文献夹；重复复用；不可写库和输入错误 |
| 文献面板：本篇／稍后阅读、搜索、RIS、粘贴、清单移除／撤销 | 两个真实任务视图；元数据详情不再重复铺陈 | 搜索、批量保存、导出、异步切换、撤销 |
| 设置：配色／字号／题名字体 | 直接影响可读性，保留主层 | 明亮／纸色／深色／系统、高字号、持久化 |
| 作者／元数据自动查询 | 单独开关，后台无候选弹窗 | 关闭后的迟到结果不能改写当前卡片 |
| 指标年份、下载／更新 | 明确数据年份；来源品牌不占主页面 | 本地、离线和自备指标回退；错误状态 |
| 更多设置：自动更新插件、本地／离线指标、导入、清缓存 | 低频项集中折叠，无分页 | 原生更新策略持久化；设置界面无来源列表 |
| 版本说明／检查更新／完成 | 页脚稳定可见；检查后可安装可用版本 | 失败可重试；哈希验证由 Zotero 管理；当前版说明 |
| 网络：库／文献夹、搜索范围／搜索、刷新 | 决定研究范围与检索语义；范围下的数量明确 | 子文献夹、全库保持、空状态、取消、过期结果清理 |
| 网络列表、继续显示、导出 | 用列表承载完整结果，图只承载局部关系 | 50 条一批；导出完整结果；题名无重叠 |
| 详情：返回、打开条目／全文、作者、文献夹、读取引文 | 每项都能完成下一步阅读行为 | 焦点历史；缺附件禁用；来源页定位；作者查询 |
| 三种关系过滤、引用依据 | 区分引用、已有相关、同名署名；证据按需看 | 不造幽灵边；不将同名视为消歧；冲突不连接 |
| 关系图／收起、节点、平移、缩放、复位 | 按需局部图；最多 12 邻居；列表始终完整 | 点击跟随、拖动、键盘、方向箭头、取消拖动 |

## 证据与限度

每轮原始截图和检查记录保存在开发机隔离测试输出中；发布文档仅保留当前版本代表截图，避免把旧版状态当成现状。自动遍历原生引文标记是回归覆盖，不等同人工全文标注的精确率／召回率。乱码年份、跨页截断和仍有歧义的条目会保留未匹配状态。

最新测试、真实论文与安装证据见 [验证记录](VALIDATION.md)，实现策略见 [调研与决策](RESEARCH.md)。
