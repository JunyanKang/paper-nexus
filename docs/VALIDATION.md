## 资料与方法

使用 Bringmann 2018 视网膜综述及 Alexander 2023 Nature Communications 14:1753 等 PDF；文档书籍示例取其实际书目。作者查询核对 DOI 10.1371/journal.pone.0059247 和 10.1038/s41467-023-37408-w。CSL 格式用 Watson／Crick 1953 书目验证输出。

锁屏阶段无法完成连续的真实鼠标操作复核。网络测试使用隔离环境中的计时器推进动画帧；设置文档截图关闭动画后截取稳定状态。它们是原生引擎的程序化事件、布局与渲染证据，不是物理触控板流畅度认证。最终版本的真实触控板、读者子窗口键盘焦点与所有动态过渡仍需解锁后补充人工检查。此前与锁屏及未完成动画相关的失败没有记为通过。

合成 2000 篇文献的工作线程测量来自本轮前期同一网络实现，不能替代 2000 篇真实文献库的读入测量。主题结果未经过人工金标准评估；同名作者未做身份消歧，引用边不表达支持或反对。未逐刊核验 JCR 数值，未认证 Windows／Linux、其他 Zotero 版本或所有 PDF。免费翻译接口的现场成功不保证持续可用。

## 发布资产

XPI 仅包含运行文件。源码 ZIP 来自经审阅的 Git 索引；原生桌面驱动、测试 PDF、文献库、缓存、日志及凭据留在本地。发布脚本核对文件名单与文档链接，并从 GitHub 下载资产复核 SHA256、更新清单 SHA512 和源码一致性。公开更新传输的独立结果随发布资产提供。
