## 解释范围

本地主题向量来自固定版本 MiniLM；名称来自保留完整名词短语的本地提取。用户开启 API 模式时，由所选模型为实际分组命名。少量旧外文书目、只有题名或信息不完整的记录仍可能得到宽泛或不够自然的名称；主题质量尚未经过人工金标准系统评估。单篇论文可以形成独立主题，但其节点类型与展开行为仍为主题。

作者目前按完整署名合并，没有 ORCID 或人工消歧；同名不同人、同人不同写法尚可能分错。只有姓氏或缩写的扩展文献不据此构造虚假的合作关系，论文仍可在主题与搜索中查看。

私人适配器的检索指标有小幅点估计改善，但置信区间跨零，不能宣称已证明主题聚类更好。通用包不含适配器，个人包仅增加适配器参数，不含训练语料或导出书目。

较早完整引文指针回归中，“Repeated pointer movement over bibliography keeps cleaned hover” 出现 H1T2／Naro 2017 不一致；本轮未完成该广泛场景的修复确认。专项上角标及工作线程等价性通过不能覆盖此项。Windows／Linux、其他 Zotero 版本与所有 PDF 未认证。
