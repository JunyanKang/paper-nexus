# Paper Nexus 0.4.4 验证记录

2026-10-05 · macOS Apple Silicon · Zotero 10.0.6-beta.1+77a1c03f7。

本次发布通过 **125 项自动化测试、31 套桌面测试，共 561 项桌面检查**。桌面操作使用隔离资料库；每套结果与本版插件文件摘要绑定。测试通过不代表所有 PDF 和网络环境均无错误。

## 本版核验

- 主题覆盖菜单、摘要、保存、设置与本地网络；十套配色正文／次要文字在基础表面的对比度至少 4.5:1。旧版主题偏好映射、资源解码、监听器卸载、子窗口取消与异常移除清理已检查。
- 设置、保存、文献清单、网络、引文、摘要和菜单逐页检查：统一紧凑字号／行高、无外边框、隐藏滚动条、十套主题和系统模式、纸色／深色实机界面、小窗口和大字号。
- 更新状态与按钮同排；三枚引文操作图标同尺寸；按四字标签收窄的菜单；鼠标和方向键共用一个活动项；菜单无蓝色焦点框；多文献悬停过渡。
- 期刊论文隐藏出版社，包括延迟补全路径；图书与章节保留出版社。
- 真实 Slonacker 1897、Wood 1917、Walls 1942 连续书籍引文验证；小窗口下按钮和长内容仍可访问。
- 四类直接设置、行内展开文献、上层界面暂存与恢复、跨文档配色同步；文献清单 Esc 先收起详情再关闭，与焦点恢复；已有条目位置；保存／去重／新建文献夹；错误输入、候选过滤和延迟响应隔离。
- 摘要无标题栏、两端对齐、最大侧宽 440 px；鼠标离开题名后淡出，移入摘要保持，真实鼠标按下／松开验证重试不移除面板。保存窗口无重复标题，文献库／文献夹同行。
- 上标字形重建核验 `RPB1²⁶` 的两个数字，以及完整 `SPO11²,⁵⁹`、多篇列表／区间、`PRDM9⁶⁰`、`Bowtie2⁷⁹` 和 `ggplot2⁹²`，排除作者单位编号。
- 摘要翻译的原文切换、过时响应隔离、失败保留原文、可选引擎／目标语种、密钥隔离与流式协议。腾讯、微软现场返回中文；Google 在当前网络不可用。大模型以模拟请求检验协议与密钥安全，未消耗用户真实模型额度，未做翻译语义准确率基准。
- 自动／手动更新、失败重试、20 秒检查和 120 秒安装等待、卸载清理与最终 XPI 安装。

PubMed 检查 PMID 26658507、23555005、33208928；PMC 检查 PMC3598659。本轮现场查询未填写 API key，取得摘要、作者与文章标识符。凭据路由用合成 key 测试；私人密钥不进入源码或发布包。
