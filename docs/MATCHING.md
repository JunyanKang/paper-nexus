# 核对文献信息

[阅读指南](GUIDE.md) · [常见问题](FAQ.md)

## 引文对应是否正确

悬停编号或作者年份，检查卡片中的题名、作者和年份。可明确定位的引文只显示对应论文；不能唯一定位时保留相关候选，不把不确定信息当作确定结果。

DOI 图标可打开论文页面，定位入口可返回正文引用位置。扫描件、特殊排版或不完整的参考文献可能影响识别，可通过本篇参考文献列表核对。

## 补全摘要与发表信息

点击更新图标重新查询。出现多个候选时，核对题名、作者、年份和 DOI 后再选择。部分文献没有公开摘要，可在 Zotero 条目中自行补充。

期刊论文显示可获得的期刊、卷期、页码与年份；书籍和章节使用对应出版信息；预印本显示平台和发布日期，与正式发表版本分开。

## 论文已经保存

保存按钮会变为打开。若存在重复条目，选择要打开的记录；整理重复项可使用 Zotero 的合并功能。
