# 查看和更新引文信息

[使用指南](GUIDE.md) · [常见问题](FAQ.md)

## 查看正文引用

将鼠标停在编号或作者年份引文上，查看对应文献。多篇连引会连续显示；使用卡片中的定位入口可以返回各处引用位置。

## 信息不完整或对应有误

打开文献卡片的 **更多 → 更新**，查找补充信息。若出现多个候选，请核对题名、作者和年份再选择。题名后的链接图标可打开 DOI 页面，帮助确认原文。

扫描版 PDF 或排版特殊的文献可能无法正确识别引用，可先通过本篇文献列表查找，或在 Zotero 条目中补充书目信息。

## 文献已在库中

卡片会显示所在文献库和文献夹，保存入口改为打开已有条目，便于继续阅读和整理。
