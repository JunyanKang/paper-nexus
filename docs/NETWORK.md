# 浏览文献网络

[返回首页](../README.md) · [使用指南](GUIDE.md)

![作者网络](images/network.png)

从主面板右上角的网络图标进入，也可以使用 Zotero 工具菜单中的 Paper Nexus。

## 从一个研究问题开始

| 想做什么 | 操作 |
|---|---|
| 看某个项目的文献 | 首行选择文献库和文献夹 |
| 找到一位作者的工作 | 搜索作者名，选择结果并聚焦关联 |
| 浏览研究内容的分布 | 切换“主题”，点击主题节点 |
| 找下一篇需要阅读的论文 | 选择当前论文，查看引用文献或点“扩展引文” |
| 回到引用依据 | 在节点详情的关系列表中点击来源图标 |

作者模式以完整署名组织论文，主题模式根据本地题目与摘要中的研究词项分组。主题名称显示代表词，点击节点即可浏览组内论文。

## 定位与聚焦

在首行搜索题名或作者，选择结果后画面自动定位。点击节点在右侧查看题名、摘要、所在文献夹和直接关联；窄窗口中详情会移到下方。

点“聚焦关联”或双击节点，可集中查看它周围的关系。点“全景”回到当前范围。较长的关系列表先显示 16 条，点击“更多关联”继续查看。

![主题网络与节点详情](images/topics.png)

## 扩展参考文献

点击“扩展引文”将参考文献加入网络：

- 选中论文：扩展该论文的参考文献。
- 选中作者或主题：扩展组内论文的参考文献。
- 未选中节点：扩展当前范围中已读取的参考文献。

实心论文节点表示本地条目，空心论文节点表示扩展文献。作者信息不足的文献会按引用来源组织，便于回到原论文。展开文献后可从节点详情继续阅读或保存。

## 移动画布

| 操作 | 效果 |
|---|---|
| 双指滑动／拖动画布空白处 | 平移 |
| 捏合／鼠标滚轮 | 围绕指针缩放 |
| 拖动节点 | 调整节点位置 |
| 方向键 | 平移 |
| 加减号 | 缩放 |
| `0` 或“全景” | 回到整体视图 |

概览会收拢密集文献；放大或聚焦可展开更多节点和标签。动画结束后画面保持稳定，便于阅读。

## 让网络随文献库成长

新增、修改或删除 Zotero 条目后，网络会自动刷新。初次显示最多 600 篇本地论文，使用载入更多入口继续增加；引文扩展也按批次加入。加载时可查看进度或取消，当前已显示内容会保留。
