# 从作者探索合作网络

[产品首页](../README.md) · [使用指南](GUIDE.md) · [设置](SETTINGS.md)

朋友圈把文献库中的作者与共同论文连接起来。阅读一篇论文后，沿着熟悉的名字发现合作者，再回到他们一起完成的研究。

点击 Paper Nexus 面板右上角的网络图标，选择文献库或文献夹。朋友圈会自动在后台准备，首次完成前显示进度；期间可以继续阅读。

<p align="center"><img src="images/network.png" width="700" alt="以作者为中心查看直接合作关系"></p>

## 找到一个人，进入一个圈

输入姓名或其中一部分，选择结果，以该作者为中心查看关系。姓名顺序、空格与连字符不同也可匹配。选择 **一级** 查看直接合作者，选择 **二级** 扩展到他们的合作圈。

总览中的群组展示经常合作的作者。点击群组可以细看成员；悬停姓名或节点，同时突出显示对应作者与直接联系。连线表示共同署名：共同论文越多，线越粗、群组越靠近。悬停时只有附近的不相关节点渐变变淡，远处仍保持清楚。点击作者可查看相关论文。

## 在网络与论文之间来回

| 想做什么 | 操作 |
| :--- | :--- |
| 进入群组或查看作者 | 点击节点或姓名 |
| 返回上一级 | 单击画布空白，或按 Esc |
| 返回全览 | 双击画布空白 |
| 清除搜索 | 点击输入框右侧的清除图标 |
| 移动与缩放 | 拖动画布，使用触控板或滚轮 |
| 居中显示 | 点击左下角的适应视图图标 |

选中文献后，可以查看期刊、年份和页码，阅读原文、译文或双语摘要，打开 DOI 或加入稍后读。识别到 ORCID 的作者可通过图标访问主页。

## 随文献库一起更新

新增或修改文献后，朋友圈会在后台更新。重复打开同一范围会复用已有结果；需要重新整理时，点击网络左上角的刷新图标。

朋友圈使用本地文献中的作者信息，无需 API 账号。姓名、署名或合作记录不完整时，可先完善 Zotero 条目，再刷新网络。
