# 从作者探索合作网络

[产品首页](../README.md) · [使用指南](GUIDE.md) · [设置](SETTINGS.md)

朋友圈把文献库中的作者与共同论文连接起来。阅读一篇论文后，沿着熟悉的名字发现合作者，再回到他们一起完成的研究。

在 Zotero 文献库工具栏点击 Nexus 图标，或在阅读面板右上角点击网络图标，选择文献库或文献夹。朋友圈会自动在后台准备，首次完成前显示进度；期间可以继续阅读。

<p align="center"><img src="images/network.png" width="700" alt="以作者为中心查看直接合作关系"></p>

## 找到一个人，进入一个圈

输入姓名或其中一部分，图谱会直接显示匹配的作者姓名，也可同时呈现多个匹配。选择一个结果，以该作者为中心查看关系。姓名顺序、空格与连字符不同也可匹配。点击其他作者可沿着合作关系继续探索。

总览中的群组展示经常合作的作者。放大某个区域后，间距足够的小节点会逐步显示作者姓名，可直接点击查看；缩小则收起细节。点击群组也可以细看成员；悬停姓名或节点，同时突出显示对应作者与直接联系。连线表示共同署名：共同论文越多，线越粗、群组越靠近。悬停时只有附近的不相关节点渐变变淡，远处仍保持清楚。点击作者可查看相关论文。

## 在网络与论文之间来回

| 想做什么 | 操作 |
| :--- | :--- |
| 进入群组或查看作者 | 点击节点或姓名 |
| 返回上一级 | 单击画布空白，或按 Esc |
| 返回全览 | 点击左上角朋友圈图标，或双击画布空白 |
| 清除搜索 | 点击输入框右侧的清除图标 |
| 移动与缩放 | 拖动画布，使用触控板或滚轮 |
| 居中显示 | 点击左下角的适应视图图标 |

选中文献后，可以查看期刊、年份和页码，阅读原文、译文或双语摘要，打开 DOI 或加入稍后读。已确认 ORCID 的作者节点带有清晰的淡绿色外圈，可从右侧作者信息栏的 ORCID 图标访问主页。右键点击作者节点或 ORCID 图标可添加、修正或清除链接；Mac 触控板使用双指点按，也可 Control＋点击。输入 ORCID 编号或完整链接后保存，修改会保留在本机；需要时可恢复自动识别。未找到 ORCID 时，直接点击灰色图标即可添加。

论文可按期刊影响力、年份或题名排序，支持正向与反向。

文献列表、朋友圈与设置之间可直接切换，一次只显示一个页面。从单篇文档进入时，网络和设置右上角提供文献列表按钮。关闭网络后再打开，会回到原来的作者、子图与缩放位置；点击左上角朋友圈图标可回到总览。

## 了解一位研究者的学术历程

图谱中已关联 ORCID 的作者，姓名旁会显示学术履历图标。点击后，左侧按时间浏览公开的教育、任职、资助、荣誉与成果，右侧保留该作者的本地论文。不同经历用颜色区分，可按类别筛选、调整时间顺序，向下滚动即可继续浏览。

<p align="center"><img src="images/career.png" width="700" alt="左侧浏览公开学术经历与成果，右侧查看文献库中的相关论文"></p>

成果卡显示完整发表信息，提供 DOI、保存／打开、稍后读和复制引文。在作者栏的 ORCID 图标旁悬停，可展开编辑按钮并修正链接；输入框内的小扫把清空链接，点击保存后生效。

返回箭头或 Esc 会回到原来的网络位置。履历显示作者在 ORCID 公开的内容，没有公开的经历不会补写。

## 随文献库一起更新

新增或修改文献后，朋友圈会在后台更新。重复打开同一范围会复用已有结果；需要重新整理时，点击网络左上角的刷新图标。

朋友圈使用本地文献中的作者信息，无需 API 账号。插件会在后台依据论文 DOI 与署名核对可获得的 ORCID，手动修正的链接优先保留。姓名、署名或合作记录不完整时，可先完善 Zotero 条目，再刷新网络。
