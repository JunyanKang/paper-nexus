# 浏览文献网络

[返回首页](../README.md) · [使用指南](GUIDE.md)

从主面板右上角的网络图标进入，也可以使用 Zotero 工具菜单中的 Paper Nexus。

## 从主题或作者出发

| 视图 | 圆点代表什么 | 连线代表什么 | 点击后 |
|---|---|---|---|
| 主题 | 一个研究主题 | 所含论文之间的引用或内容关联 | 展开该主题的论文，查看论文列表 |
| 作者 | 一位完整署名的作者 | 共同发表的论文 | 查看其论文和合作作者 |

在画布左上角的图标中切换作者、主题。

主题名称使用研究短语；悬停、选中和右侧详情使用同一名称。作者跨年份汇总，节点名称不带年份。每对节点只画一条线，线宽随去重后的关联依据增加。

## 定位与聚焦

总览把关系密切的主题或作者收拢为节点团，显示一个代表名称。点击节点团进入成员网络；“返回总览”或 Esc 返回原来的视角，并保留搜索内容。悬停不会突然展开整团标签。

主题模式中，关键词可以同时命中多个节点团；无关部分淡出，点击感兴趣的节点团继续探索，再点击具体主题查看论文。

作者模式中，输入姓名并选择结果，即可进入以该作者为中心的合作网络。“一级”显示直接合作作者，“二级”增加这些作者的合作关系。连线来自共同论文，详情中可以查看相应文献。大型合作网络按需“展开更多”。

点击搜索框右端的清除图标，清空输入并返回网络总览。

首行可选择文献库或文献夹。论文详情提供摘要、所在文献夹、打开条目、阅读全文和稍后读等操作。

## 随文献库增长

新增、修改或删除条目后，网络在后台更新。已有题名和摘要向量、相似度索引与主题名称会被复用，只重新处理变化的内容。更新时保留当前画面和节点位置，画布内显示分步进度，可以继续平移、缩放和查看已有结果。

第一次打开时逐行显示本次需要的步骤：完成的步骤变绿，正在进行的显示进度，尚未开始的保持灰色。点击尚未完成的结果会提示“正在进行中，请稍后”。取消后，已经完成的缓存会保留，下一次可继续使用。

在“网络 → 分组与命名”选择分析方式：

| 方式 | 主题网络 | 作者网络 |
|---|---|---|
| 本地算法 | 本地模型分组，自动提取研究短语命名，无需密钥 | 按真实合著关系划分合作群体，以代表作者的完整姓名标记 |
| 大模型 · API | 根据题名、摘要决定主题归属并命名 | 根据已有合著关系划分合作群体，并选择真实成员作为代表 |

两种方式都保留作者身份、论文和真实引用依据。大模型不会生成合著连线或改写作者姓名。大型联合署名群体继续使用本地算法处理。接口暂不可用时，界面会说明并显示本地结果。

主题模式的相似度和排版仍由本地模型支持；选择 API 不会删除或替代已安装模型。翻译与网络分析共用服务商密钥，可分别选择模型。每位用户的网络由自己的文献库生成，无需自己训练模型。

## 模型与后台索引

首次使用主题网络，请在设置的“本地模型”一行安装或导入模型。轻量通用适合日常使用；生命医学是面向英文生物医学内容的可选模型。切换模型会使用各自的索引，原有索引继续保留。

处理进度按步骤分行显示：读取文献、准备模型、分析内容、计算关联、组织主题与布局。完成步骤变绿，后续步骤保持灰色。大模型分析会按实际任务增加对应步骤。

新增或修改文献时，后台只编码变化的文本，并复用未变化的近邻结果；主题组织会随新的关系调整。无需关闭阅读窗口等待。再次打开相同网络可继续使用已有结果。


## 保存与继续

参考文献列表、引用位置所需的解析数据，以及不同文献库／文献夹的作者和主题网络会自动保存在本机。重复打开相同范围、模式和模型时复用结果；PDF 文件变化后重新读取，条目变化后更新相应分析。Zotero 重启后会先核对当前书目信息，再复用匹配的网络。

网络只纳入所选本地文献库或文献夹中的论文。已解析参考文献可以提供本地论文之间的引用关系，不会自动加入库外条目。缓存自动限制容量，较早的结果可能被清理，之后按需重新生成。
