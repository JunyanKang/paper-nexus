# 本地文献网络

入口：Zotero 工具菜单 → Paper Nexus，或阅读器内的Paper Nexus 面板 → 文献网络。不必先打开 PDF。

1. 选择个人库、群组库或具体文献夹。子文献夹包含在范围内。
2. 搜索题名、作者、期刊或 DOI；切到“已索引全文”可搜索 Zotero 已有的本地附件文字，查看命中片段并打开附件。
3. 选择文献，查看引用关系、已有相关条目、同名署名。每种关系可以分别过滤。
4. 点击顶部“读取引文”读取所选 PDF 的参考文献并匹配本地库。点击关系行中的“引用／被引用”查看依据，并可打开文末来源页。
5. 点击“关系图”探索局部关联，拖动节点、平移背景、放大／缩小／复位。箭头指向被引文献；虚线代表同名署名。点击节点切换中心，返回按钮恢复上一篇。

默认以关联列表为主，图只绘制前 12 项，完整结果仍在列表。左侧文献每次显示 50 条，可继续加载；导出列表使用完整搜索结果，不局限于当前可见页。修改库内容后，刷新按钮会提示变化。

## 证据边界

- 元数据来自现有 Zotero 条目，包括可读群组库；不修改库内容。
- 引用关系来自已打开／显式读取 PDF 的文末书目。首次打开并不代表全库 PDF 已经解析，也不代表所有引文都已连接。
- 正文悬停匹配另外使用作者、年份／后缀、编号和文末列表复核，不直接采用原生跳转目的地。
- DOI 冲突不回退到模糊题名；无 DOI 时要求唯一的完整规范题名、年份和首作者。重复条目或不能确定的记录不强行连接。
- 作者边要求完整署名匹配。相同姓名仍可能是不同人，故称“同名署名”；仅有首字母缩写时不生成边。
- 全文搜索按字面词组匹配，不是语义搜索。只读已有索引，不自动 OCR。未索引、过大（超过 16 MB 的单个文字缓存）或读取失败会计数显示。
- 文末引用来源页不等同于正文中的具体引用语境；当前引用依据展示文末条目及其页码，不声称定位每一次引用。
- 本地网络不联网，不将全文、书目或关系上传。可选作者／元数据／指标查询遵循各自开关。
