# 常见问题

[返回首页](../README.md) · [安装与更新](INSTALL.md) · [使用指南](GUIDE.md)

## 安装后从哪里打开？

打开 PDF，点击工具栏上的 Paper Nexus 图标。文献网络也可从 Zotero 的工具菜单进入。刚升级后若未出现，请关闭并重新打开当前 PDF。

## 需要分别下载插件和模型吗？

不需要。下载安装器后，首次使用点击 **下载并安装**；已有模型时可选 **仅更新插件**。两种方式都会引导你完成插件安装。

## 需要账号或 API key 吗？

文献网络和 PubMed 摘要查询可直接使用。E-utilities key 可选；使用大模型翻译时需填写相应服务商的密钥。文献网络无需配置翻译密钥。

## 摘要没有显示怎么办？

先用题名后的 DOI 图标确认论文，在 **更多 → 更新** 中补充信息，然后重试。也可在 Zotero 条目中补充摘要后重新打开。部分文献没有公开摘要。

## 如何翻译摘要？

在 **设置 → 阅读** 选择翻译服务和目标语言，然后在摘要窗口点击译文或双语。大模型服务的配置方法见[翻译设置](MODELS.md)。

## 如何复制 APA、AMA 或期刊格式的引文？

在 **设置 → 阅读 → 引文格式** 中选择格式，再点击文献更多菜单中的复制图标。定位图标则用于跳回正文引用位置。

## 文献已经在库里了？

卡片会显示所在库和文献夹，保存按钮变为打开。存在多个位置时可查看并选择已有条目。

## 为什么没有 IF 或分区？

只有取得相应期刊指标时才显示，缺失不代表零。悬停已有指标可查看年份和学科，参见[期刊指标](METRICS.md)。

## 网络里的内容太多，怎么找？

先选择项目文献夹缩小范围，再搜索主题关键词或作者。点击节点团进入细节，单击空白返回上一级，双击空白回全览。

## 网络还在准备，可以继续阅读吗？

可以。右上角会显示准备进度，其他阅读操作可继续使用。

## 如何更新？

使用 **设置 → 网络 → 检查更新**，也可从[发布页](https://github.com/JunyanKang/paper-nexus/releases/latest)下载安装器。1.0.1 及更早版本请先用新版安装器升级一次。
