# 常见问题

[产品首页](../README.md) · [安装指南](INSTALL.md) · [使用指南](GUIDE.md)

## 安装后没有看到入口

文献库工具栏和 PDF 阅读器工具栏均有 Nexus 图标。文献库入口打开朋友圈，阅读器入口打开本篇参考文献。刚完成更新时可重新打开 Zotero；仍未出现可到 **工具 → 插件** 检查是否已启用。

## 摘要没有显示

先用 DOI 图标确认论文，再在 **更新信息** 中补充信息后重试。也可在 Zotero 条目中补充摘要。部分文献没有公开摘要。

## 引文没有识别，或对应论文不正确

确认正文可以选中文字。扫描件需先进行文字识别，特殊排版也可能影响识别。可在本篇参考文献列表中核对题名、作者与年份。反馈时请提供论文 DOI 和出错页面。

## 为什么有的论文没有 IF 或分区

仅在获得对应期刊数据时显示，缺失不代表零。书籍、预印本等非期刊条目不显示期刊指标。悬停已有指标可查看年份和学科。

## 翻译连接失败

普通服务可在 **设置 → 阅读** 中更换后重试。大模型服务请检查密钥、模型名和接口地址，再点击 **保存并测试**。详见[翻译设置](MODELS.md)。

## 网络还在准备怎么办

首次准备会显示动画与进度，期间可以继续阅读。关闭网络窗口后后台准备仍会继续。可先选择较小的文献夹查看；明确提示失败时，点击重试。

## 朋友圈中有重复作者

同名可能属于不同的人。点击节点查看共同论文，核对 Zotero 中的作者姓名和署名信息。补充后刷新网络；明显错误可附相关论文信息反馈。

## 想反馈一个问题

请在 [GitHub Issues](https://github.com/JunyanKang/paper-nexus/issues) 描述期望结果与实际情况，附系统、Zotero 和插件版本。截图前请隐藏私人文献、账户和密钥。
