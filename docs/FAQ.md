# 常见问题

[返回首页](../README.md) · [安装与更新](INSTALL.md) · [使用指南](GUIDE.md)

## 安装后从哪里打开？

打开 PDF，点击工具栏上的纸张放大镜图标。文献网络也可从 Zotero 的工具菜单进入。若刚升级，可关闭并重新打开当前 PDF。

## 需要分别下载插件和模型吗？

在发布页下载对应系统的安装器即可。首次使用选“下载插件与模型”；已有模型、只需更新插件时，使用“下载插件”。下载后按照提示把 XPI 加入 Zotero。插件也能在设置中补装模型。

## 每个人都需要训练模型吗？

不需要。安装器获取已经训练好的通用或医学语义模型，插件根据自己的文献库生成本地索引和网络。首次建立索引不等于训练模型。

## 本地模型负责聚类，还是负责生成主题名称？

本地模型将题名与摘要转为语义向量，用于构建主题关系；主题名称从论文研究内容和生物医学术语中提取。作者合作网络来自作者署名和共同论文。两种网络均在本机完成。

## API key 必须填写吗？

默认本地主题分析不需要。PubMed 摘要查询也可以直接使用；填写 NCBI E-utilities key 后可提高允许的请求频率。在设置的“阅读”页填写，点击“测试”确认连接；点击 E-utilities 名称可打开注册页面。

## 摘要没有显示，怎么处理？

先用题名后的 DOI 图标检查论文是否对应，在更多菜单中点击更新图标补充信息，然后重试摘要。阅读页的 E-utilities 测试可帮助检查连接。也可以先把摘要保存到 Zotero 条目中，再重新打开卡片。

## 翻译和网络共用密钥吗？

分别配置。两者可以使用不同厂商和模型；即使选择同一厂商，也要在各自配置页保存密钥。操作方法见 [设置与服务](SETTINGS.md)。

## 如何选择翻译服务？

在“设置 → 阅读”的翻译区域选择腾讯、微软、Google 或“大模型 · API”，设置目标语言。大模型配置页提供“保存”和“保存并测试”。回到摘要，点击译文或双语图标。

## 如何复制 APA、AMA 或期刊格式的引文？

在“设置 → 阅读 → 引文格式”选择格式，再打开文献更多菜单，点击叠页复制图标。箭头定位图标用于跳回正文引用位置。

## 文献已经在库里了？

卡片会显示所在库与文献夹，保存按钮变为打开。存在多个位置时可查看并选择已有条目。

## IF 和分区在哪里？

期刊名称所在行显示可用的 IF 和 Q 分区。悬停指标可查看年份与学科详情。期刊信息更新后，指标会随匹配结果刷新。

## 网络中的论文太多，如何找到需要的内容？

先选项目文献夹，再搜索题名或作者。点“聚焦关联”缩小到邻近网络；用作者／主题切换组织方式，放大查看细节。网络仅包含所选本地文献库或文献夹中的论文。

## 如何更新？

打开“设置 → 网络 → 检查更新”。1.0.1 及更早版本请先通过新版安装器升级一次。也可从 [最新发布页](https://github.com/JunyanKang/paper-nexus/releases/latest) 下载安装器更新，设置和稍后阅读清单继续保留。
