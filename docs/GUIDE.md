# 使用指南

安装请见 [首页](../README.md#安装与更新)。本插件运行于 Zotero 桌面阅读器，不是 Chrome 扩展。

## 悬停与多篇引用

将鼠标停在正文作者年份或编号上。卡片显示当前引文对应的文末条目；一处多篇时连续排列，共用圆角外框、细线分隔，没有顶部翻页。窗口缩小时，面板宽度、字号与内边距同步收缩；高度最多占阅读区的 56%，较长列表在面板内滚动。无法确定的项不会借用相邻论文的信息；可能出现部分匹配提示。

保存／打开、稍后读、…位于右上角。已有文献会显示 Library 和完整 Collection 路径；存在多份时先选择已有条目。保存时可以选个人库、可写群组库、已有文献夹或新建子文献夹。个人 Library 本身由 Zotero 管理，插件不创建第二个个人库。

…仅包含更新信息、另存到…、复制引用、设置。更新信息会过滤明显冲突的候选；后台自动查询不打开候选窗口。未获取可靠结果时保留原始书目，保存前可编辑。

## 摘要与 PubMed／PMC

悬停或键盘聚焦题名，摘要会在旁边贴边展开，自动选择空间较宽的一侧。摘要可以移入阅读和滚动，不重复显示题名。左右空间均不足时，摘要接在当前条目下方，整个浮窗继续受高度限制。Esc、关闭按钮或点击正文可收起。

先读取文献记录与本地库的摘要；缺失时查询 PubMed／PMC 和 Europe PMC，必要时回退 Crossref。PubMed 支持 PMID、DOI 和题名检索，候选仍须通过题名、作者、年份及标识符的一致性检查。结构化摘要保留段落；可用时附 PubMed／PMC 原文链接、研究类型和关键词。内容来自数据库，不生成推测性总结，也不覆盖本地库的书目信息。

查询不等待后台作者任务；总等待上限为 12 秒，网络不可用时显示“重试”。成功结果缓存在本机，下次可直接读取。“清除查询缓存”会同时清除摘要缓存。

设置 → 更多设置 → **PubMed API key（可选）**。填写 NCBI E-utilities API key 后离开输入框即保存；清空后离开可移除。不填也可使用，主要区别是 NCBI 允许的请求频率较低，单篇查询不一定更慢。输入框隐藏密钥，密钥存于本机 Zotero 偏好设置，只通过 HTTPS POST 发给 NCBI，不放在请求地址、阅读清单、源码或发布包中。

## 阅读清单与网络

Paper Nexus 面板的“本篇文献”检索当前 PDF 参考文献，“稍后阅读”保留待处理文献。可搜索、批量保存和导出 RIS；移除清单后可以撤销。复制或保存不会把题名格式标记作为 HTML 执行。

文献网络可从面板或 Zotero 工具菜单进入。作者默认一行显示前三位和后三位的姓氏，完整姓名在悬停提示中；点击“…”在原位置展开完整名单，不重复堆叠。点击作者可搜索本地署名。关联文献的年份、引用方向和同名署名合并显示；点击“引用”或“被引用”查看依据，并可跳回来源 PDF。操作、来源证据和功能边界详见 [本地网络](NETWORK.md)。

## 设置

配色、字号和题名字体立即生效。字号设置作为悬浮卡的最大字号，小阅读区自动紧凑显示，放大窗口后恢复。作者列表与文献信息分别控制自动查询。期刊指标可指定年份；缺失时不回退到其他年份冒充该年。

“更多设置”包含可选 PubMed API key、自动更新插件、本地指标、离线指标、导入和清缓存。导入格式见 [指标说明](METRICS.md)。版本号打开发布页；检查更新后可安装新版本。检查结果固定显示在按钮下方，不随设置内容滚动。检查超过 20 秒会结束等待并允许重试；连接失败时提供“打开发布页”。自动更新需 Zotero 全局更新开关也处于开启状态。

插件各页面统一隐藏滚动条；滚轮、触控板和键盘仍可滚动，内容较长时可继续向下阅读。

## 无匹配时

常见原因包括扫描 PDF 无文字层、乱码、跨页截断、原文作者年份不一致、同作者同年无法唯一消歧或库内缺少目标文献。可选中完整参考文献使用识别，或粘贴到面板。对于正文只给姓氏但没有年份的普通作者提及，插件不会把整篇所有同姓论文都弹出来。
