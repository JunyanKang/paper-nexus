# 使用指南

安装请见 [首页](../README.md#安装与更新)。本插件运行于 Zotero 桌面阅读器，不是 Chrome 扩展。

## 悬停与多篇引用

将鼠标停在正文作者年份或编号上。卡片显示当前引文对应的文末条目；一处多篇时，用下拉列表或上一篇／下一篇切换。无法确定的项不会借用相邻论文的信息；可能出现部分匹配提示。

保存／打开、稍后读、…位于右上角。已有文献会显示 Library 和完整 Collection 路径；存在多份时先选择已有条目。保存时可以选个人库、可写群组库、已有文献夹或新建子文献夹。个人 Library 本身由 Zotero 管理，插件不创建第二个个人库。

…仅包含更新信息、另存到…、复制引用、设置。更新信息会过滤明显冲突的候选；后台自动查询不打开候选窗口。未获取可靠结果时保留原始书目，保存前可编辑。

## 阅读清单与网络

研联面板的“本篇文献”检索当前 PDF 参考文献，“稍后阅读”保留待处理文献。可搜索、批量保存和导出 RIS；移除清单后可以撤销。复制或保存不会把题名格式标记作为 HTML 执行。

文献网络可从面板或 Zotero 工具菜单进入。操作、来源证据和功能边界详见 [本地网络](NETWORK.md)。

## 设置

配色、字号和题名字体立即生效。作者列表与文献信息分别控制自动查询。期刊指标可指定年份；缺失时不回退到其他年份冒充该年。

“更多设置”包含自动更新插件、本地指标、离线指标、导入和清缓存。导入格式见 [指标说明](METRICS.md)。版本号打开发布页；检查更新后可安装新版本。自动更新需 Zotero 全局更新开关也处于开启状态。

## 无匹配时

常见原因包括扫描 PDF 无文字层、乱码、跨页截断、原文作者年份不一致、同作者同年无法唯一消歧或库内缺少目标文献。可选中完整参考文献使用识别，或粘贴到面板。对于正文只给姓氏但没有年份的普通作者提及，插件不会把整篇所有同姓论文都弹出来。
