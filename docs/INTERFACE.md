# 界面与主题

Paper Nexus 分为阅读与本地探索两个工作场景。悬浮引文保留随读随查的小窗口；完整文献网络按需打开，不把关系图塞进引文卡片。

## 操作路径

- **阅读清单**：本篇文献／稍后阅读共用搜索与列表。点击条目在原位置展开卡片，保留其他结果；收起或 Esc 返回列表。
- **文献网络**：保留范围、搜索、结果和当前关联。打开设置或引用依据时暂时收起网络界面，返回后保留原状态。
- **设置**：外观、阅读、翻译、数据四个直接标签。方向键切换标签；不再通过“更多设置”逐层展开。
- **保存**：先选 Library／Collection，再按需新建文献夹或编辑书目。批量保存直接进入目标选择，未确认的项仍留在清单。
- **返回**：子界面暂时隐藏上一界面，不同时叠放多个可操作窗口；返回、关闭或 Esc 恢复上层的搜索、滚动与焦点。保存进行中暂时禁用返回，避免重复写入。

## 设置分类

| 分类 | 内容 |
| --- | --- |
| 外观 | 跟随系统、十套主题、纹理开关、字号、题名字体 |
| 阅读 | 自动补全作者、自动补全文献、可选 PubMed API key |
| 翻译 | 引擎、目标语言；使用大模型时直接显示连接配置 |
| 数据 | 指标年份、下载／导入、本地和离线指标、清除缓存、自动更新插件 |

版本与手动检查更新固定在同一页脚，不受分类切换和内容滚动影响。

## 主题覆盖

全部插件界面使用一套语义配色：背景、阅读表面、正文、次要文字、强调、选中、分隔、错误、遮罩及阴影。

| 界面 | 覆盖内容 |
| --- | --- |
| 阅读清单、行内详情 | 搜索、标签、条目、按钮、状态、队列 |
| 单篇／多篇引文 | 题名、作者、期刊、指标、DOI、库位置、操作 |
| 摘要与翻译 | 原文／译文、来源、等待、失败、重试、连接面 |
| 操作菜单 | 默认、悬停、键盘活动项、禁用 |
| 保存与批量保存 | 目标选择、编辑、验证错误、进行中 |
| 已有位置、候选、粘贴、联网确认 | 内容、字段、操作与键盘焦点 |
| 本地网络、引用依据 | 筛选、列表、详情、署名、关系类型 |
| 局部关系图 | 节点、边、标签、选中与键盘焦点 |
| 设置与更新 | 四类页面、主题预览、开关、下拉框、反馈 |

主题同步到已打开的阅读器和主窗口；新窗口继承当前设置。旧版明亮／纸色／深色偏好分别保留为银翼／织麦／月岩。跟随系统会实时响应系统深浅变化。

主题纹理可关闭；开启时位于面板、对话框和摘要的独立背景层，使用高遮罩保持正文可读，卡片与菜单保留实色。系统“降低透明度”会禁用纹理，“减少动态效果”会停用切换动画。插件不改变 PDF 页面内容、Zotero 原生文件选择器或系统对话框。

滚动条统一隐藏，保留滚轮、触控板与键盘访问。小窗口优先保留标签导航和操作页脚，中间内容可滚动；不以压缩正文到不可读大小来强行容纳所有选项。
