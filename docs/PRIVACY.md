# 数据与隐私

[产品首页](../README.md) · [使用指南](GUIDE.md) · [设置](SETTINGS.md)

Paper Nexus 在 Zotero 内运行，没有自己的账号、云端文献库或使用行为统计服务。

## 保存在本机的内容

设置、稍后读、已核对的作者与 ORCID、摘要、发表信息和朋友圈保存在本机，便于再次打开。朋友圈依据本地署名关系整理，不向大模型发送文献库。分组不会改写 Zotero 原始条目。

## 哪些操作会联网

| 操作 | 使用的资料 |
| :--- | :--- |
| 查找文献信息、作者与摘要 | DOI、PMID、题名等检索信息，必要时用作者和年份核对 |
| 摘要翻译 | 当前摘要、目标语言及对应服务配置 |
| 测试翻译连接 | 内置示例句 |
| 更新插件与资料 | 插件、期刊指标、引文格式和翻译模型列表 |

朋友圈会在后台分批以论文 DOI 查询公开书目信息，用对应署名核对 ORCID；不会仅凭姓名绑定身份。

文献查询可能使用 PubMed／PMC、Europe PMC、Crossref、OpenAlex 或 Semantic Scholar。取得的摘要保留来源，不改写 Zotero 的摘要字段。打开 DOI 或 ORCID 页面会访问相应网站。只有打开学术履历时，插件才向 ORCID 请求该编号的公开个人资料与经历，并在本机缓存以便再次查看；不会上传文献库或修改 ORCID 记录。手动修正的 ORCID 链接同样只保存在本机。

选择原文不会触发翻译。译文由你选择的服务提供，适用该服务的数据政策与费用规则。

## 密钥、导出与卸载

可选的 E-utilities key 与翻译配置保存在本机。翻译密钥存入本机凭据存储，仅向对应服务发送。

复制引文和导出 RIS 包含书目信息，不包含密钥。公开反馈前，请遮盖截图中的敏感文献与账户信息。

卸载插件不会删除 Zotero 文献。偏好与缓存可能仍保留在本机，便于重装恢复。
