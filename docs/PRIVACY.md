# 数据与隐私

[返回首页](../README.md) · [使用指南](GUIDE.md) · [指标说明](METRICS.md)

Paper Nexus 在 Zotero 内运行。默认使用独立安装的本地模型在本机构建主题网络与搜索；插件没有自己的账户、云端文献库或使用行为统计服务。

## 哪些操作会联网

| 操作 | 发送内容或下载内容 | 使用目的 |
|---|---|---|
| 补全文献信息／摘要 | 当前条目的 DOI、PMID、题名或检索词，必要时用作者／年份核对 | PubMed／PMC、Europe PMC、Crossref 的文献查询 |
| 摘要翻译 | 当前摘要、目标语言及所选服务需要的配置 | 用户选择的免费通道、已安装翻译插件或自配模型服务 |
| 引文格式 | 所选 CSL 样式及其依赖的标识 | 从官方 CSL 仓库下载格式文件，优先使用已安装格式 |
| 期刊指标准备 | 下载可用的离线数据文件 | 本机按刊名／ISSN 匹配，不上传整库 |
| 更新模型预设 | 下载 Paper Nexus 官方维护的模型目录，不发送 API Key 或文献内容 | 更新全部厂商的推荐模型与接口预设 |
| 大模型主题分析（手动启用） | 新增或内容变化的论文题名、摘要、临时文献标识，以及候选已有主题的名称和少量代表题名；不发送作者字段、PDF 全文或附件 | 交由所选厂商决定主题分组并命名 |
| 大模型作者分析（手动启用） | 作者标识、姓名、少量论文题名和已有合著关系；不发送 PDF 全文或附件 | 划分合作群体并选择代表作者 |
| 模型连接测试 | 内置的示例句与示例论文标题，不读取本地文献库 | 分别检查翻译与聚类模型 |
| 检查／安装更新 | GitHub 发布信息、更新清单与 XPI | 查询新版本，交由 Zotero 验证并安装 |

选择“原文”不触发摘要翻译。若之前已选择译文或双语，后续摘要会沿用该模式。第三方服务有各自的数据政策和可用性限制；机构敏感内容宜使用获准的服务或本机模型。

## 本地保存

偏好、阅读清单、查询缓存、题名与摘要的语义向量、网络分组与布局、引用位置解析数据及已解析书目保存在 Zotero 数据目录中的插件子目录。CSL 文件按需缓存在该目录中。网络图中的显示合并不删除或修改 Zotero 原始条目；明确点击保存时才创建或复用文献条目与文献夹。

NCBI API key 可选，保存在本机偏好中，通过 HTTPS POST 发送给 NCBI；不放入查询 URL 或文献导出。模型服务的密钥使用本机加密凭据存储，不读取或修改 Paper Voice 的密钥。自定义服务地址、接口和凭据由用户配置；其计费遵循该服务规则。

## 反馈与导出

RIS 和复制引文面向书目内容，不包含 API 密钥。提交问题时只附允许公开的论文信息、截图和操作步骤；请先遮盖文献库中的敏感题名、姓名、账户及密钥。

卸载插件不会删除用户的 Zotero 条目。停用或卸载后，插件缓存与偏好可能仍保留在本机；这有助于重装恢复，也意味着卸载不等于清除所有本地数据。

本地模型安装仅向清单内的公开资源地址请求模型、运行组件和许可文件，不上传文献。模型更新只检查公共版本目录。个人索引保存在 Zotero 数据目录；完整安装包和模型包均不包含用户书目。
