# 数据与隐私

[返回首页](../README.md) · [使用指南](GUIDE.md) · [指标说明](METRICS.md)

Paper Nexus 在 Zotero 内运行。使用独立安装的本地模型在本机构建主题网络与搜索；插件没有自己的账户、云端文献库或使用行为统计服务。

## 哪些操作会联网

| 操作 | 发送内容或下载内容 | 使用目的 |
|---|---|---|
| 补全文献信息／摘要 | 条目的 DOI、PMID、题名或检索词，必要时用作者／年份核对 | PubMed／PMC、Europe PMC、Crossref、OpenAlex、Semantic Scholar 的文献查询；缺少摘要的论文也会在后台逐批查询 |
| 摘要翻译 | 当前摘要、目标语言及所选服务需要的配置 | 用户选择的免费通道、已安装翻译插件或自配模型服务 |
| 引文格式 | 所选 CSL 样式及其依赖的标识 | 从官方 CSL 仓库下载格式文件，优先使用已安装格式 |
| 期刊指标准备 | 下载可用的离线数据文件 | 本机按刊名／ISSN 匹配，不上传整库 |
| 更新模型预设 | 下载可选模型列表；账号查询可能需要向对应服务商发送密钥，不发送文献内容 | 更新可选翻译模型；查询账号可用模型时，密钥仅发送给对应服务商 |
| 模型连接测试 | 内置的翻译示例句，不读取本地文献库 | 检查翻译模型 |
| 检查／安装更新 | GitHub 发布信息、更新清单与 XPI | 查询新版本，交由 Zotero 验证并安装 |

选择“原文”不触发摘要翻译。每次打开摘要默认显示原文。第三方服务有各自的数据政策和可用性限制；机构敏感内容宜使用获准的服务或本机模型。

摘要补取保留来源，仅补充插件中的阅读和网络信息，不改写 Zotero 原始条目。相关来源：[NCBI 使用说明](https://www.ncbi.nlm.nih.gov/About/disclaimer.html)、[OpenAlex 数据说明](https://help.openalex.org/)。

## 本地保存

设置、阅读清单、网络和阅读记录保存在本机。网络图中的显示合并不删除或修改 Zotero 原始条目；明确点击保存时才创建或复用文献条目与文献夹。

NCBI API key 可选，保存在本机偏好中，通过 HTTPS POST 发送给 NCBI；不放入查询 URL 或文献导出。翻译模型服务的密钥使用本机加密凭据存储，不读取或修改 Paper Voice 的密钥。自定义服务地址、接口和凭据由用户配置；其计费遵循该服务规则。

## 反馈与导出

RIS 和复制引文面向书目内容，不包含 API 密钥。提交问题时只附允许公开的论文信息、截图和操作步骤；请先遮盖文献库中的敏感题名、姓名、账户及密钥。

卸载插件不会删除用户的 Zotero 条目。停用或卸载后，插件缓存与偏好可能仍保留在本机；这有助于重装恢复，也意味着卸载不等于清除所有本地数据。

下载与更新本地模型不会上传文献。公开安装包不包含用户的文献库。
