Paper Nexus 是免费的 Zotero 插件，将引文预览、摘要阅读、论文收藏和作者合作网络连在一起。读到感兴趣的引用，就地了解它；发现值得追踪的研究者，再沿着合作关系与学术履历继续探索。

## 阅读不断线

悬停正文引文，查看对应论文的题名、作者与发表信息；再悬停题名，阅读摘要。**原文、译文、双语**随时切换，无需离开正在读的页面。

<p align="center"><img src="docs/images/translation.png" width="680" alt="引文卡片旁展开双语摘要，可切换原文与译文"></p>

## 把线索留下来

在本篇参考文献与稍后读之间切换，随手保存论文、打开已有文献、复制引文，或跳回正文中的引用位置。同一套操作也适用于网络中的论文与学术履历中的成果。

<p align="center"><img src="docs/images/hover.png" width="420" alt="文献卡片包含发表信息、DOI、保存、稍后读和复制引文入口"></p>

## 看见研究者之间的联系

**朋友圈**从你的 Zotero 文献库出发，呈现作者与共同论文。按文献夹聚焦一个研究领域，搜索姓名、探索合作者，再回到相关论文。共同发表记录决定联系的强弱。

<p align="center"><img src="docs/images/network.png" width="700" alt="作者合作图谱与所选作者的本地论文"></p>

## 了解名字背后的学术历程

从已关联 ORCID 的作者进入学术履历，沿时间浏览公开的教育、任职、资助与成果。右侧保留本地论文，让人物经历与手边文献互相参照。

<p align="center"><img src="docs/images/career.png" width="700" alt="公开学术历程与本地论文并列展示"></p>

## 开始使用

适用于 **Zotero 10.0.5–10.0.x**，macOS 与 Windows 使用同一个 **XPI**。

1. 在[发布页](https://github.com/JunyanKang/paper-nexus/releases/latest)下载 XPI，无需解压。
2. 在 Zotero 的 **工具 → 插件 → 齿轮 → 从文件安装插件** 中选择它。
3. 打开 PDF 悬停引文；或在文献库工具栏点击 Nexus 图标，探索朋友圈。

引文阅读与朋友圈无需注册账号。摘要翻译可选择普通翻译服务或自己的大模型 API。公开摘要与 ORCID 信息的完整程度因文献和作者而异。
